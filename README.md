# Performance & Load Testing Suite - Python & Locust

## 📌 Project Overview
This project contains an automated performance and load testing suite built using **Python** and **Locust**. It simulates concurrent user traffic to evaluate system responsiveness, throughput, and error rates under load.

## 🛠️ Tech Stack & Tools
* **Language:** Python[cite: 6]
* **Load Testing Tool:** Locust[cite: 6]
* **Interface:** Locust Web UI (localhost:8089)[cite: 6]

## 📁 Repository Contents
* **`locustfile.py`**: Defines simulated user behavior (`HttpUser`), task weights, and think times using `between`.
